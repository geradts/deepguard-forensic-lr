# Detector-output pipeline

## 1. Run detector adapters

Export one CSV per detector. Each CSV should contain at least:

```text
video_id,score
```

Metadata columns are recommended:

```text
label,source_id,subject_id,generator_id,dataset
```

## 2. Merge FTCN + Xception

```bash
python tools/merge_detector_outputs.py \
  --ftcn ftcn_results.csv \
  --xception xception_results.csv \
  --output deepguard_features.csv
```

The merger preserves metadata and creates separate detector feature columns. It does not average detector confidences.

## 3. Add other feature extractors

Additional rows/features can be generated by the multimodal feature extractors. Keep each detector output separate so the LiR model can learn their evidential contribution on development data.

## 4. LiR

Pass the resulting frozen development feature table to `lir_handoff.yaml` or the v9 dashboard.

**Do not interpret detector scores directly as likelihood ratios.**
